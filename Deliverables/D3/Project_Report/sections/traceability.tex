\section{Traceability}

The \repolink{Deliverables/D3/Traceability_Matrix/main.pdf}{requirements traceability matrix} links
\TraceRequirements{} Deliverable 1 requirements to \TraceJira{} Jira issues, \TracePulls{} merged pull
requests and \TraceEntries{} automated tests and test groups. It is generated from recorded test runs and
a snapshot of the pull requests, so it can be rebuilt and checked rather than maintained by hand. The
full table is also available as \repofile{Deliverables/D3/Traceability_Matrix/traceability-matrix.csv}.

Table~\ref{tab:chain} follows one requirement along the whole chain. FR-RD-06.8 says that once a rider is
accepted on a ride, their other active requests for rides departing within two hours are withdrawn and
those owners are told.

Two limits apply to the chain. Implementation and tests were often written by different people at
different times, so one requirement can span several Jira issues and pull requests, as it does here. And
\PullsNoJira{} of the \PullsMerged{} merged pull requests name no Jira key, so the chain cannot start from
Jira for those.
